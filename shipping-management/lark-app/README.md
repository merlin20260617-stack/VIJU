# VIJU 成品仓发货管理

## 需求背景
供成品仓每天录入销售订单、按装货顺序完成发货，并统一汇总客户订单、产品出货及库存。

## 用户希望的功能
每页100客户位置；客户产品逐条维护与Excel导入；装货完成撤回；24小时生产待入库；严格防止并发超发。

## 站点已提供的能力
独立Lark Base及11张真实业务表已创建。工作台已实现真实角色读取、订单录入与修改、每页100客户位置、装货完成撤回、客户产品逐条维护与Excel/CSV导入、24小时生产待入库及客户/产品/库存汇总。业务状态通过Lark服务端桥接独立事务服务，页面不回退到本地示例数据。

## 当前状态与边界
本版本用于Preview验收，正式版尚未发布；真实业务闭环验证通过前不能用于正式发货。库存以独立事务存储为事实源，Lark台账为同步投影；事务提交与台账同步状态分开提示，同步结果未知时停止重写并保留待核查任务。首次读取最多20,000条业务/审计实体，达到上限时需升级为分区查询。角色由AccessRoles表维护，未配置角色或重复配置时拒绝访问；Preview仅验证管理者准入，不能代表普通员工多角色验收。事务服务必须保持私有，仅服务端持有访问凭据。
