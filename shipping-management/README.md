# VIJU 成品仓发货管理

独立项目路径：`merlin20260617-stack/VIJU/shipping-management/`。面向成品仓每天录单、按顺序装车和查看汇总数据。

## 当前交付状态

本版本为**可运行的本地功能预览与业务核心**，尚未连接真实 Lark，未发布 Preview 或正式版。预览显著标识本地模式，数据仅保存在当前浏览器。不要录入真实客户订单或把它作为多人生产系统。

当前环境没有此前远程项目的 `lark-base-database` 技能或本项目 Catalog。`server/lark-port.mjs` 在未绑定时明确拒绝读写。没有复用其他平台的应用 ID、数据表或凭据。

## 已实现

- 每页固定10×10客户位置，显示客户代码/名称、订单号、产品代码/名称、箱数、整板、余箱和所需板位。余箱标红；超出屏幕可横向滚动。一个位置可显示客户多张订单。
- 手工录入多产品销售订单、装货顺序与订单修改。单个订单或客户当前全部订单完成装货后，从工作台移入已完成列表。
- 装货前检查合计可发库存。撤回需填写原因，恢复库存后可修改并重新装货。
- 工厂、仓库、产品、客户逐条新增/修改。产品按 carton 计量，分别维护 pcs/carton 和 cartons/pallet。
- 客户和产品支持 .xlsx / UTF-8 CSV 批量导入，工作表选择、字段匹配、错误行提示、重复代码报错/跳过/更新、确认后整批写入。保留文本前导零及Excel纯0数字格式。最多10MB / 5000行；不支持旧版 .xls、加密工作簿或公式单元格。提供CSV模板，可由Excel另存为xlsx。
- 期初库存、生产批次、生产完成后**精确24小时**待入库隔离。可发库存独立于生产待入库量；每15秒刷新预览，成熟时重新计算。
- 当日已发/待发/生产量、客户订单汇总、产品汇总、库存结余、日期范围/工厂/仓库/客户/产品筛选，支持订单明细CSV导出。
- 操作审计、纯函数事务、版本冲突检测、幂等请求和仓库写权限业务规则。预览角色仅模拟，不能视作真实权限验证。

## 运行与验证

需要 Node.js 22+，无第三方运行依赖。

```sh
cd shipping-management
npm test
npm run preview
```

打开 `http://127.0.0.1:4190`，点击“载入示例数据”。建议新版 Edge/Chrome（需要 Web Locks 与 DecompressionStream deflate-raw）。

## 统计口径

数量均为箱，12pcs/carton表示一箱12小件，并非12箱。

整板数 = floor(订单明细箱数 / 下单时每板标准箱数)；余箱 = MOD；板位数 = ceil。不同产品不默认混板，客户有多张订单时逐单显示，不把不同标准相加后再除。

可发库存 = 期初 + 已满24小时生产量 − 当前已完成装货数量。生产待入库 = 当前未满24小时批次数量。预计结余 = 可发库存 − 全部待装货订单数量，允许负数以展示缺货，但禁止超库存确认装货。

顶部“当日订单量/待装货”按订单日期；“当日已发货”按实际完成日期。汇总报表按订单日期范围统计当前状态。“等等”不作为订单状态，只有待装货、已装货。撤回后当前状态报表会冲回，历史动作留在审计中；历史时点库存快照不在此版本范围。

期初仅在仓库启用前录入。已完成订单先撤回再改，暂不提供部分发货、退货、盘点调整或生产批次更正。已发生业务记录不删除。客户主数据不限制100条；按当天订单分配位置，每页100个客户，支持翻页。完成装货后位置留空，当日其他客户不因完成动作前移。
