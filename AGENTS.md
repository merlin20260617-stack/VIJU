# VIJU project convention

All new VIJU platforms belong here as independent sibling directories. Lark hosts application runtime and business data; GitHub stores source only. User requirement applies to all their projects: never introduce another paid service or additional charges without first explaining necessity, provider/data location, pricing and Lark alternatives and obtaining explicit confirmation. Do not merge into other platforms or message another task unless requested. Preserve unrelated code, data, roles and credentials; never commit secrets or business records.
